Third-Party Notices for fastp-1.3.3-windows-ucrt64
===================================================

This file summarizes third-party components included in the Windows release
ZIP for this repository.

This is an informational notice file, not legal advice. Each third-party
component remains under its own license terms.


Packaged runtime files
----------------------

The release ZIP includes the following runtime files from MSYS2-UCRT64:

  fastp.exe
      Built from fastp 1.3.3 source with the Windows/MSYS2-UCRT64
      compatibility patch in this repository.

  libdeflate.dll
      MSYS2 package: mingw-w64-ucrt-x86_64-libdeflate 1.25-1
      Upstream: https://github.com/ebiggers/libdeflate
      License: MIT

  libhwy.dll
      MSYS2 package: mingw-w64-ucrt-x86_64-highway 1.4.0-2
      Upstream: https://github.com/google/highway
      License: Apache-2.0

  libisal-2.dll
      MSYS2 package: mingw-w64-ucrt-x86_64-isa-l 2.31.1-1
      Upstream: https://www.intel.com/content/www/us/en/developer/tools/isa-l/overview.html
      License: BSD-3-Clause / BSD-3-Clear style license

  libgcc_s_seh-1.dll
  libstdc++-6.dll
      MSYS2 package: mingw-w64-ucrt-x86_64-gcc-libs 16.1.0-2
      Upstream: https://gcc.gnu.org
      License: GPL-3.0-or-later WITH GCC-exception-3.1

  libwinpthread-1.dll
      MSYS2 package: mingw-w64-ucrt-x86_64-libwinpthread 14.0.0.r37.g2bfe61fba-1
      Upstream: https://www.mingw-w64.org/
      License: MIT AND BSD-3-Clause-Clear
